# Vendored: real SO-101 arm

`so101_new_calib.urdf` + `assets/*.stl` are vendored verbatim from
[TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100),
commit `7629d2ad9853d10fb903093a33ef6114099d97e5` (2026-08-05), path
`Simulation/SO101/`. Licensed Apache-2.0 (see `LICENSE` in this directory,
copied from the same repo).

This replaces the earlier fixture robot (`fixtures/robot/test_arm.urdf`,
a made-up placeholder with no real-world counterpart) as the source for
`fixtures/spatial-training/robots/so101/`, generated by
`tools/make_real_so101_bundle.py`. `test_arm.urdf` itself is left
untouched — the old TEACH pipeline's `ar_datapipe.robot_model.DEFAULT_URDF`
still points at it, unaffected by this swap.

Not modified from upstream except: mesh `filename=` paths in the vendored
bundle copy (`fixtures/spatial-training/robots/so101/robot.urdf`) are
rewritten from `assets/...` to `meshes/...` to match this repo's existing
bundle layout convention — a path change only, not a geometry change.
