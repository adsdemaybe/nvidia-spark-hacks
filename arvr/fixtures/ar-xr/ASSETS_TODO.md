# Missing binary visual assets

`scene.json` (generated by `tools/make_fixtures.py`) references four GLB
files that are **not** in this directory yet:

```
table.glb
cube.glb
bin.glb
robot.glb
```

These are not fabricated by the fixture generator — a placeholder cube
mesh with the right filename would silently pass every schema check while
being useless for actually looking at PLACE/TWIN mode. Drop in real (or
simple primitive) GLBs here before Andrew starts on Phase 2 (Place); until
then, RealityKit/Three.js code can still be built and unit-tested against
`scene.json`'s manifest shape, it just won't have anything to render.
